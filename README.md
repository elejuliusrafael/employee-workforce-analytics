# Employee Workforce Analytics

## Project Objective

This project will analyze employee workforce data to identify meaningful patterns, trends, and insights that can support evidence-based workforce planning and organizational decision-making.

## Tools

Python, pandas, NumPy, Matplotlib, SciPy, statsmodels, scikit-learn, Jupyter, SQLite, and Microsoft Excel.
